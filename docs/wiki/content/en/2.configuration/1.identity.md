The `cfg/identity.nix` file serves as the single source of truth for your personal configuration in SDN. By editing this one file, you verify settings across the entire system.

## Configuration

Located at `cfg/identity.nix`:

```nix [cfg/identity.nix]
{
  username = "shure";
  name = "Shure Tokki";
  email = "shure@example.com";

  # Locale & Time
  locale = "en_US.UTF-8";
  timezone = "Asia/Jakarta";
}
```

## Propagation

This file is imported at the flake level and propagated to all NixOS and Home Manager modules via `specialArgs`.

*   **User Account**: Creates the user with `username` and `name`.
*   **Git Config**: Sets global git identity using `name` and `email`.
*   **System Locale**: Configures `i18n.defaultLocale` and `time.timeZone`.

## Workflow

::steps
### Edit Identity

Open `cfg/identity.nix` and update the values to match your persona.

### Apply Changes

Rebuild the system to apply your new identity.

```bash [Terminal]
nh os switch
```
::
