## Method

::steps
### Core Prerequisites

Before you begin, ensure your target machine meets the following requirements:

*   **NixOS**: An existing NixOS installation (minimal or desktop).
*   **Git**: Required to clone and manage the configuration.
*   **SSH/Keys**: If you plan to use SOPS-Nix immediately, ensure your age keys are ready.

### Clone the Repository

Clone the SDN repository to your local machine. We recommend placing it in your home directory.

```bash [Terminal]
git clone https://github.com/shuretokki/dotnix.git ~/sdn
cd ~/sdn
```

### Configure Your Identity

The single most important step is editing your identity. This file controls the username, locale, and timezone applied across the entire system.

```nix [cfg/identity.nix]
{
  username = "shure";
  locale = "en_US.UTF-8";
  timezone = "Asia/Jakarta";
}
```

### Setup Hardware Configuration

SDN needs to know about your machine's hardware. Generate a configuration or use your existing one and place it in the machine-specific directory.

```bash [Terminal]
# Generate for the current machine
nixos-generate-config --show-hardware-config > cfg/hosts/desktop/hardware-configuration.nix
```

### Apply the Configuration

Use the `nh` helper to build and switch to your new SDN environment. This command will handle the flake evaluation and system activation.

```bash [Terminal]
nh os switch .#desktop
```

::callout{icon="i-lucide-alert-circle" color="amber"}
The first build may take some time as Nix fetches dependencies. Subsequent updates will be significantly faster.
::
::

## Binary Acceleration

To avoid compiling large packages from source, SDN is pre-configured to use several binary caches. These are defined in the flake and will be used automatically.

### Public Caches

*   **shuredotnix.cachix.org**: Primary cache for SDN-specific packages.
*   **hyprland.cachix.org**: Optimized binaries for the Hyprland compositor.
*   **vicinae.cachix.org**: Binaries for the Vicinae launcher.
