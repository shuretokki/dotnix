**SDN** (shuredotnix) is a [NixOS](https://nixos.org) configuration designed for developers and power users. It leverages [Nix Flakes](https://wiki.nixos.org/wiki/Flakes) and [Home Manager](https://nix-community.github.io/home-manager/) to deliver a reproducible, aesthetically unified computing environment.

### Dependencies
- [NixOS](https://nixos.org) (24.11+)
- [Hyprland](https://hyprland.org/) (via flake input)
- [Stylix](https://github.com/danth/stylix) (via flake input)

## Architecture

SDN uses a **4-Layer Architecture** to organize system configuration:

| Layer | Path | Scope |
| :--- | :--- | :--- |
| **Core** | `src/lib/core/` | System foundations: hardware, network, security. Runs as root. |
| **Display** | `src/lib/display/` | Visual stack: Hyprland, Waybar, Stylix, SDDM. |
| **Home** | `src/lib/home/` | User space: Terminals, browsers, media apps via Home Manager. |
| **Profiles** | `src/lib/profiles/` | High-level presets that compose layers (e.g., `desktop`, `server`). |

## Configuration

User configuration is separated from implementation logic:

| Directory | Purpose |
| :--- | :--- |
| `cfg/identity.nix` | Username, locale, timezone. |
| `cfg/theme.nix` | Theme preset and visual overrides. |
| `cfg/hosts/` | Per-machine hardware configurations. |
| `cfg/secrets/` | Encrypted secrets via [SOPS-Nix](https://github.com/Mic92/sops-nix). |
