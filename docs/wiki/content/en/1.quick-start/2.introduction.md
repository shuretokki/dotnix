Welcome to **SDN** (shuredotnix), a premium NixOS configuration designed for developers and power users.

## What is SDN?

SDN is more than just dotfiles. It is a strictly architected framework that leverages **Nix Flakes** and **Home Manager** to deliver a consistent, reproducible, and aesthetically pleasing computing environment.

We organize the system into a clear **4-Layer Architecture**:

## Key Features

This configuration is built with specific goals in mind:

- **Powered by [Flakes](https://wiki.nixos.org/wiki/Flakes)**: Ensures hermetic, reproducible builds.
- **[Identity-Centric](https://nixos.org)**: System-wide preferences are decoupled from implementation.
- **Secrets via [sops-nix](https://github.com/Mic92/sops-nix)**: Encrypted, secure secret management.
- **Pre-configured Shells**: Ready-to-use dev environments.

::callout{icon="i-lucide-info" color="blue"}
**Forkable by Design**: SDN is built to be a template. Clone it, change `identity.nix`, and make it yours.
::
