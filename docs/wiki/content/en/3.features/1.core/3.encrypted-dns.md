SDN enforces system-wide encrypted DNS using **dnscrypt-proxy**. This ensures your ISP cannot see which websites you visit and protects against DNS spoofing.

## Features

- **DNS-over-HTTPS**: All queries are encrypted.
- **Ad Blocking**: Automatically filters 400k+ ad/tracker domains via [OISD](https://oisd.nl/).
- **Redundancy**: Balances traffic between Quad9, Cloudflare, and Mullvad.

## Usage

### Verification

To verify that your DNS is encrypted:

```bash [Terminal]
sudo dnscrypt-proxy -resolve google.com
```

### Updates

The ad-blocking list updates automatically every day. To force an update:

```bash [Terminal]
sudo systemctl start dnscrypt-blocklist
```

## Captive Portals

Connecting to public Wi-Fi requires accessing a login page which often breaks with encrypted DNS. SDN includes a helper utility to handle this.

::callout{icon="i-lucide-wifi" color="amber"}
**Public Wi-Fi**: Use the `captive-portal` command to temporarily disable encryption.
::

::steps
### Enable Portal Mode

When you connect to a new network and need to log in:

```bash [Terminal]
sudo captive-portal on
```

### Log In

Open your browser and complete the Wi-Fi login process.

### Restore Security

Once connected, re-enable security immediately:

```bash [Terminal]
sudo captive-portal off
```
::

## Configuration

The logic resides in `src/lib/core/network/dns.nix`. It is enabled by default in the **Core** layer.

```nix [src/lib/core/network/dns.nix]
services.dnscrypt-proxy2 = {
  enable = true;
  settings = {
    server_names = [ "quad9-dnscrypt-ip4-filter-pri" "cloudflare" "mullvad" ];
    # ...
  };
};
```
