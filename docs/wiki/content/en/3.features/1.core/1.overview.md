The `src/lib/core` directory contains the foundational system configuration. These modules run as root and define the hardware/OS baseline.

## Key Modules

### Audio
Configures **PipeWire** for low-latency audio.
- Enabled globally (ALSA, PulseAudio, JACK support).
- Includes `wireplumber` for session management.

### Network
- **NetworkManager**: Manages Wi-Fi and wired connections.
- **Firewall**: `nftables` based, blocks incoming traffic by default.
- **SSH**: Hardened configuration (no root login, keys only).

### Security
- **Sops-Nix**: Encrypted secrets management.
- **Hardening**: Kernel parameters and userspace hardening.
- **DNS**: [Encrypted DNS](/en/features/core/encrypted-dns) via dnscrypt-proxy.

### GPU
Hardware acceleration drivers located in `src/lib/core/gpu/`.
- **NVIDIA**: Proprietary drivers with Wayland support.
- **AMD**: Open source Mesa drivers.

## Usage

Core modules are imported by **Profiles** (e.g., `src/lib/profiles/desktop`). You rarely need to edit them unless changing system-wide policy.
