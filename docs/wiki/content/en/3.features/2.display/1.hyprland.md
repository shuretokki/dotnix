SDN provides a hyper-polished **Hyprland** configuration that balances aesthetics with raw productivity.

## Architecture

The configuration logic is split to allow upgrades without losing your personal tweaks.

- **Engine** (`src/lib/display/compositor/`): Defines the core behavior, animations, and system integrations (Stylix, Waybar).
- **User Config** (`cfg/hyprland/`): Place your custom keybinds, window rules, and environment variables here.

## Features

- **Instant Switching**: Workspaces switch instantly with no animation delay for maximum responsiveness.
- **Smart Gaps**: Gaps automatically collapse when only one window is open (configurable).
- **Swallowing**: Terminals are hidden ("swallowed") when launching GUI applications.
- **Focus**: "Follow Mouse" is enabled by default.

## Customization

To add your own rules or bindings, look into `cfg/hyprland/`:

::card-group
  :::card
  ---
  icon: i-lucide-keyboard
  title: Keybinds
  ---
  Add your custom shortcuts in `cfg/hyprland/binds.nix`.
  :::

  :::card
  ---
  icon: i-lucide-app-window
  title: Rules
  ---
  Define window rules (float, opacity) in `cfg/hyprland/rules.nix`.
  :::
::

## Default Keybinds

| Key | Action |
| :--- | :--- |
| `Super` + `Q` | Close active window |
| `Super` + `Return` | Open Terminal |
| `Super` + `Space` | Open Launcher (Vicinae) |
| `Super` + `E` | Open File Manager |
| `Super` + `F` | Toggle Fullscreen |
