SDN uses [Stylix](https://github.com/danth/stylix) to enforce a unified look across the entire OS. By separating specific color values from the system logic, you can switch themes globally with a single line of code.

## Architecture

The theming system follows the SDN separation of concerns:

- **Logic** (`src/lib/display/themes/`): Defines *how* to apply colors to apps (Hyprland borders, Waybar modules, GTK).
- **State** (`cfg/theme.nix`): Defines *which* theme preset to use.
- **Presets** (`cfg/themes/`): Contains the actual assets (wallpaper.png, colors.yaml).

## Configuration

To change your theme, edit `cfg/theme.nix`:

```nix [cfg/theme.nix]
{
  # Select a preset from cfg/themes/
  theme.preset = "pro";

  # Optional: Override specific value
  # theme.visual.rounding = 8;
}
```

::prose-tip
**Available Presets**: Browse the `cfg/themes/` directory to see all available theme options.
::

## Creating a Preset

You can add your own themes by creating a new directory in `cfg/themes/`.

::steps
### Create Directory

Create a folder for your theme, e.g., `cfg/themes/ocean/`.

### Add Definition

Create `cfg/themes/ocean/default.nix`. It must define a wallpaper and a base16 scheme.

```nix [cfg/themes/ocean/default.nix]
{ pkgs, ... }:
{
  theme = {
    scheme = ./scheme.yaml; # Base16 color scheme
    polarity = "dark";

    visual = {
      rounding = 0;
      opacity = 0.9;
      blur = true;
    };
  };
}
```

### Activate

Update `cfg/theme.nix` to use your new preset:

```nix [cfg/theme.nix]
theme.preset = "ocean";
```
::
