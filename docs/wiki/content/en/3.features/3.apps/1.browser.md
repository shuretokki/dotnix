SDN bundles a hardened configuration for **Zen Browser**, prioritizing privacy and performance out of the box.

## Policies

These policies are applied system-wide and cannot be overridden by the user, ensuring a baseline of privacy.

| Policy | Value | Rationale |
|--------|-------|-----------|
| `DisableTelemetry` | `true` | Prevents Mozilla/Zen from collecting usage metrics. |
| `DisableFirefoxStudies` | `true` | Blocks A/B testing and "Heartbeat" experiments. |
| `DisablePocket` | `true` | Removes the non-free "Read Later" service. |
| `HttpsOnlyMode` | `"force_enabled"` | Upgrades all HTTP connections to HTTPS. |

## Privacy Defaults

SDN configures sensible defaults that strike a balance between privacy and usability.

| Preference | Value | Rationale |
|------------|-------|-----------|
| `webgl.disabled` | `false` | Kept enabled for map/rendering support (unlike strict hardening). |
| `geo.enabled` | `false` | Disables the Geolocation API. |
| `network.trr.mode` | `2` | Uses DNS over HTTPS (DoH) with native fallback. |

## Extensions

The following extensions are pre-installed via the bundler:

- **uBlock Origin**: The gold standard for content filtering.
- **Bitwarden**: Open-source password management.
- **Dark Reader**: Generates dark mode for every website.
- **SponsorBlock**: Skips YouTube sponsor segments.

## Configuration

The declaration lives in `src/lib/home/apps/browser/`.

```nix [src/lib/home/apps/browser/default.nix]
programs.zen-browser = {
  enable = true;
  policies = {
    # Privacy policies defined here
  };
};
```

::callout{icon="i-lucide-wrench" color="primary"}
**Customization**: You can override specific preferences in your user's `home.nix` by setting `programs.zen-browser.preferences`.
::
